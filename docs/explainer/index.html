calibrate-pro

Calibrate Windows displays, and label every number with where it came from.

What it does for you

If your screen shows colour wrong, every photo, grade and render you judge on it is judged against a bad reference. calibrate-pro finds your displays, plans a correction toward a target such as sRGB or DCI-P3, writes an ICC profile and a 3D LUT, and reports how close the result should be. Each figure says whether it was measured with an instrument or estimated from a panel record, and nothing changes on your display until you confirm an exact preview.

  • Evidence labelsValues read measured, estimated, simulated, replayed or Not measured.
  • Preview, then confirmA display change needs an exact preview and an explicit yes; declining writes nothing.
  • Sealed outputProfiles and LUTs are published with a manifest of SHA-256 hashes you can recheck.
  • 58 panel recordsCharacterized primaries and gamma for common monitors, plus a generic fallback.

Source: README.md at 6e983bb (version 2.0.1)

How it works, one step at a time

Scroll, or use the step buttons. Every line is output from calibrate-pro 2.0.1 at commit 6e983bb, run from source on Windows. Step four calls the sensorless engine from Python on a panel record, because the test machine's own display has no record.

  1. 01

    Ask what this install can do

    calibrate-pro doctor reports versions and which capabilities the installation supports: colorimeter over HID, DDC/CI, gamma ramps and ICC profiles. It probes no display, sensor or bus, and it says so, so none of its lines claims a device is present.

    Source: calibrate_pro/commands/doctor.py

  2. 02

    Find the display, and what is closed

    detect lists the displays the machine presents and where each characterization comes from. The test display matched no panel record. status then lists every action and its state: 27 of 97 are available at this stage, and each closed one carries its reason.

    Source: calibrate_pro/application, calibrate_pro/workflow.py

  3. 03

    Choose a target

    A target fixes three things: the gamut, the white point and the tone response. Four presets cover common work, and any target can be composed from the three axes, with eleven gamuts including sRGB, BT.2020 and ACEScg, and white points named or given in kelvin.

    Source: calibrate_pro/targets

  4. 04

    Predict the error before and after

    The Dell AW3423DW record is a QD-OLED with primaries far wider than sRGB. The sensorless engine simulates the 24 ColorChecker patches through the full chain, once with no correction and once with the computed 3 by 3 matrix. Average error falls from 3.62 to 0.65 dE2000, and the worst patch from 6.64 to 2.92.

    These are predictions from the panel record. No display was measured, and the label says estimated.

    Source: calibrate_pro/sensorless/neuralux.py, verify_calibration

  5. 05

    Publish a sealed bundle

    generate-profiles writes the ICC profile and a 33-point 3D LUT into a folder you name, with a manifest holding the size and SHA-256 of each file. profiles rechecks the seal later. Pick a state in the panel: after one line was appended to the LUT, the recheck reports the bundle CHANGED and names the file.

    Source: calibrate_pro/commands/session_profiles.py

  6. 06

    A display change needs your yes

    The terminal reads and plans, and writes only files you name. Changing the display happens in the window: Detect, Method, Preview, Apply, Verify, then Save or Report. The app starts unelevated, shows the exact change first, and declining performs no write.

    This step is described from the README; the window was not driven for this page.

    Source: README.md, "Current status" and "What to test first"

Try it

From source on Windows 10 or 11 with Python 3.10 or newer, or from the Windows release build. These commands read and plan; the last one writes files only into out.

$ git clone https://github.com/HarperZ9/calibrate-pro && cd calibrate-pro
$ pip install -e ".[all]"
$ calibrate-pro doctor
$ calibrate-pro detect
$ calibrate-pro verify --target srgb_web
$ calibrate-pro generate-profiles out --target srgb_web
$ calibrate-pro profiles out

Output from calibrate-pro 2.0.1 at 6e983bb on Windows 11 with Python 3.12. Step four used SensorlessEngine.verify_calibration with an identity matrix for the uncorrected run, which is the comparison the verify command prints.

What it does not do

  • Sensorless figures are predictions from a panel record. Your unit can differ from the record; only an instrument establishes the result.
  • The modelled figure covers gamut reproduction. Tone response is outside it, so measure to establish grey tracking.
  • Windows only. The 2.0.1 artifacts are not Authenticode-signed, so check the download against SHA256SUMS.txt.
  • Hybrid calibration, which would mix a panel record with an instrument run, stays disabled.
